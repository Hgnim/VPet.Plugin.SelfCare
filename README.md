# VPet.Plugin.SelfCare

该插件开箱即用，无需任何配置。桌宠会自动根据心情来做自己想做的事情（工作、学习与玩耍），有时也会闲置一会（想休息一下）。

桌宠不想要被日程表约束，桌宠想做自己想做的事情。

[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3793331427)

This plugin works right out of the box with no configuration needed. The desktop pet will do whatever it wants based on its mood (working, studying, or playing), and sometimes it'll just hang out for a bit (wanting a break).

The desktop pet doesn't want to be tied down by a schedule; it just wants to do what it feels like doing.
